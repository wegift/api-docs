This event is sent when Runa's fraud checks block a recipient from redeeming a payout link. The link's value is not released.

Runa also tries to cancel the link. `cancelled` says whether it did:

- `true`: the link is cancelled.
- `false`: the link is still active, but its redemptions keep being blocked.

Quote the `assessment_id` when you contact us about the payout.
