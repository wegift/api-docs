This event is sent when an order finishes processing successfully. Together with [`order.failed`](/reference/2024-02-05/webhook/order.failed), it replaces [`order.completion`](/reference/2024-02-05/webhook/order.completion).

The order is in `data`, in the same shape as the completed `order.completion` payload.
