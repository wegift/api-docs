This event is essential when using the async ordering mode if you need to take action when an order has completed. It's also useful if you want to feed ordering data into your system.

The event uses the [Standard Webhooks](https://www.standardwebhooks.com/) envelope. The event type is in `type`, always `order.completed` for this event, so you can dispatch on it if your endpoint receives more than one event type. The order is in `data`, and `timestamp` indicates when the event occurred.

Failed orders are sent as a separate [`order.failed`](/reference/2024-02-05/webhook/order.failed) event. Subscribe to the event types for the outcomes you want to receive; you don't need to check `data.status`.

The event does not include the `items` field. Use the [get order](/reference/2024-02-05/endpoint/orders/get) endpoint if you need the order items.
