This event is sent when an order fails. Together with [`order.completed`](/reference/2024-02-05/webhook/order.completed), it replaces [`order.completion`](/reference/2024-02-05/webhook/order.completion).

Use `reason` to decide what to do next:

- `fraud`: Runa's fraud checks blocked the order.
- `generic`: the order failed for any other reason.
